# Фронтенд ходит в API только через сгенерированный SDK

Все запросы к бэкенду идут через клиент, сгенерированный из TypeSpec, а прямой `fetch`,
`XMLHttpRequest` и сторонние HTTP-клиенты запрещены ESLint и grep-аудитом
`mise run sdk:check`. Базовый URL и маппинг ошибок в `ApiError` живут только в
`frontend/src/lib/api.ts`, поэтому смена адреса или транспорта не расползается по компонентам.

## Consequences

- В браузере по умолчанию используется origin страницы: Next.js проксирует `/api` в Express,
  поэтому развёрнутому контейнеру нужен один публичный порт. Серверный рендеринг ходит
  напрямую по внутреннему адресу.
- Сгенерированный SDK собирается отдельным `tsc` в `dist/`: Turbopack не переписывает
  `.js`-импорты эмиттера в `.ts`.
- Тесты компонентов замещают `@/lib/api` целиком; собственный тест модуля проверяет базовый
  URL, разбор конвертов и `ApiError`.
