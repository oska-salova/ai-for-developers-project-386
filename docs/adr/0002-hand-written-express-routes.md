# Серверные роуты Express пишутся руками по контракту

Официальный серверный генератор `@typespec/http-server-js` отклонён после спайка на Express
5: `express.json()` перед сгенерированным роутером вешает запрос навсегда, битый JSON роняет
процесс, а ради прохождения `tsc` пришлось бы отключить `verbatimModuleSyntax` и
`noUncheckedIndexedAccess` во всём бэкенде. Роуты пишутся руками по типам из
`backend/src/generated/openapi.d.ts`, а расхождение ответов с контрактом ловит contract
compliance тест в `backend/src/app.contract.test.ts`.

## Considered Options

- **Сгенерированные роутеры.** Выигрыш — только роутинг, чтение тела и сериализация, около
  200 строк на пять маршрутов; цена — alpha-зависимость, ослабленный `tsconfig` и три обхода
  выше. Для первого среза не оправдано.
- **Ручные роуты по OpenAPI-типам.** Выбрано: строгость `tsconfig` сохраняется, бизнес-логика
  всё равно остаётся в нашем коде.

Пересмотреть, если ручного роутинга станет заметно больше пяти маршрутов: тогда вернуться к
генератору и осознанно принять ослабления, записав это в `AGENTS.md`.
