## Использование

В приложении два типа пользователей: владелец календаря (задаёт типы встреч и смотрит записи)
и гость (выбирает свободное время и записывается на звонок). Регистрации и авторизации нет.

Правила записи:

- Окно записи — 14 календарных дней, начиная с сегодняшнего дня; окно сдвигается с течением времени.
- Рабочие часы владельца: 09:00–18:00, часовой пояс Europe/Moscow.
- Шаг доступных стартов — 15 минут; длительность слота равна длительности типа встречи.
- Пересечение интервалов запрещено, включая частичное наложение разных типов встреч.
- Следующая встреча может начинаться в момент окончания предыдущей.
- Правила действуют и для запросов, пришедших одновременно: время занимает тот, кто записался первым.

## Сценарий владельца

1. Владелец открывает раздел «Типы встреч» и создаёт тип встречи: название, описание, длительность.
2. Владелец открывает раздел «Встречи» и видит список предстоящих встреч.

## Сценарий гостя

1. Гость нажимает «Записаться» — открывается список типов встреч, и он выбирает нужный.
2. Гость видит календарь на ближайшие 14 дней: свободные слоты доступны для выбора,
   занятые отображаются, но недоступны.
3. Гость выбирает свободный старт, указывает имя и почту и подтверждает запись.
4. Выбранное время становится занятым и больше не предлагается никому.

## Ограничения

- Регистрации и авторизации нет: разделы открыты всем.
- Владелец календаря в приложении один и задан заранее.
- Данные хранятся в памяти процесса: перезапуск сервера сбрасывает типы встреч и записи.
