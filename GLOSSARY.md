# Календарь звонков

Сервис бронирования времени для звонков: владелец календаря задаёт типы встреч, гость выбирает свободный слот и записывается.

## Language

**Владелец**:
Человек, чей календарь бронируют. Задаёт типы встреч и смотрит предстоящие встречи; в приложении он один и задан заранее.
_Avoid_: пользователь, админ, хозяин календаря

**Гость**:
Человек, который бронирует время в календаре владельца.
_Avoid_: клиент, посетитель, пользователь

**Тип встречи**:
Шаблон бронирования с названием, описанием и длительностью. Гость выбирает тип встречи до выбора времени.
_Avoid_: тип звонка, услуга, событие

**Встреча**:
Забронированный интервал в календаре владельца с выбранным типом встречи, временем, именем и почтой гостя.
_Avoid_: звонок, событие, бронь

**Слот**:
Потенциальное время начала встречи, которое сервис предлагает гостю. Занятый слот не предлагается.
_Avoid_: таймслот, ячейка, окно

**Окно записи**:
Отрезок из 14 календарных дней, начиная с сегодняшнего, внутри которого гость может выбрать слот.
_Avoid_: период бронирования, горизонт записи
